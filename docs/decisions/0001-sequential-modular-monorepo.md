# ADR 0001 — Последовательный модульный монорепозиторий

Дата: 2026-09-23. Статус: принято.

Один официальный репозиторий, короткий хакатон и три независимых Codex-сессии
требуют передачи решений через файлы, без общей памяти чатов.

Решение: ARCHITECT/CORE → FRONTEND → BACKEND → INTEGRATION, человеческие
review/commit/push между этапами. Отдельные ветки автоматически не создаются.
Документы state/progress и неизменяемые handoff передают контекст.

Два runtime-контура используют одно ядро: судейский Agent напрямую вызывает
StrategyEngine, демонстрационный API делает это через StrategyRunner.
OpenAPI v1 и fixtures фиксируются до Frontend, чтобы UI мог работать без API.
Модели core — dataclass/Protocol, API DTO появятся только в backend.

Не нужны микросервисы, брокер, база данных, auth и обязательный Docker.
Преимущество — независимый запуск judge и небольшой объём интеграции.
Цена — явное согласование контракта и обновление памяти в конце каждого этапа.

Источники: PARTICIPANT_GUIDE.md, agent_template.py, environment.py,
scoring_core.py. Шаблон требует 5 минут, руководство допускает 10:
принимаем более строгую цель 5 минут. README обязателен по заданию bootstrap,
хотя руководство называет его необязательным. Основное положение отдельно
не предоставлено; его дополнительные требования пока не проверены.

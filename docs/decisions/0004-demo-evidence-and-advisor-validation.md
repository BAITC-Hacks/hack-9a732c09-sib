# ADR 0004 — Проверяемое демо и надёжный ответ советника

Дата: 2026-09-23. Статус: superseded.

План standalone HTML-паспорта не реализовывался: его заменила проверяемая
React/Vite dashboard и live frontend/API smoke из handoff 07. Требования к
безопасному advisor и trace остаются историческим контекстом; текущая
интеграционная граница описана в `docs/PROJECT_STATE.md`.

Уточнение после проверки требований: `priorities-v2` и категории ошибок
реализованы, offline regression-тесты проходят. Live-проверка нового формата,
расширение trace и standalone HTML пока NOT_RUN/NOT_IMPLEMENTED. Появившийся
после объединения веток React frontend существует отдельно; UI E2E ещё нужен.

Пользователь поручил довести агента до демо. В DOCX UI не обязателен;
работоспособность/техника/README дают по 25 баллов, ценность 15, оригинальность 10.
Выбран CLI + standalone HTML «паспорт решения», построенный из фактического
trace и официального score. Frontend/OpenAPI не расширяются в этом scope.

В пользовательском замере OpenAI на seed100–139 приняты 37/40 ответов, три
отброшены с общим ValueError. Их точная причина неизвестна: raw responses
не сохранялись. Устраняем структурный риск permutation-output: модель
заполняет обязательную оценку приоритета для каждого фиксированного ID,
а уникальную перестановку строит код (ties по исходному порядку). Приоритет
не является прогнозом дохода или статистической уверенностью.

Добавляются безопасные категории ошибок: HTTP auth/rate limit/provider,
network/timeout, incomplete/refusal, malformed JSON/schema. Один запрос/run,
без ретраев, без raw ответов/ключей в диагностиках. Core по-прежнему получает
только перестановку и не зависит от HTTP/LLM. Политика пилотов не меняется.

Для отчёта trace получает фактические итоги проверки каждой гипотезы:
наблюдения/порог/разрешение или отказ/ресурсы. Это объяснение алгоритма,
не скрытые рассуждения модели и не вычисление KPI из noisy pilots.

Существующие замеры относятся к прежнему prompt/schema. После изменения
новые smoke-результаты сохраняются отдельно с версией советника; прежний
результат 37/40 не переобъявляется результатом новой реализации.

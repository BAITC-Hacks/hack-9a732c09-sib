# ADR 0002 — Повторные пилоты и внешний советник гипотез

Дата: 2026-09-23. Статус: implemented по прямому запросу пользователя.
Роль: CORE / INTEGRATION. OpenAPI v1 и judge-сигнатура сохранены.

Решение о провайдерах заменено [ADR 0003](0003-openai-only.md): NVIDIA удалена
по запросу пользователя; текущие режимы openai/off. Ниже сохранена история
исходного решения. Политика пилотов и защитные границы не изменены.

## Причина

Исходные три пилота позволяли масштабировать случайный положительный сигнал,
а fallback мог охватить большой убыточный сегмент. Seed 0–9: средний net
−10 647, худший −41 150. Пользователь поручил улучшить устойчивость и
подключить выданные API; выбрал NVIDIA основной, OpenAI переключаемой альтернативой.

## Решение

- `false_positive/` остаётся без HTTP, секретов, env и зависимости от LLM.
  Обязательный DeterministicAdvisor сохранён. Старый алгоритм зафиксирован
  в `strategy/legacy.py` для честного сравнения, не используется по умолчанию.
- Генератор использует публичные цены, ARPU и непересекающиеся сегменты.
  До 24 гипотез в пуле, до 6 исследуемых направлений с разнообразием текущих
  тарифов. Публичная цена не считается доказанным эффектом.
- Первый пилот до 80 контактов, подтверждения до 200; максимум 4 попытки
  на гипотезу. Для масштабирования нужны минимум 3 положительных наблюдения
  и положительный net после штрафа неопределённости 2×. Floor 1/sqrt(n) и
  дисперсия между пилотами — эвристика, не калиброванный доверительный интервал.
- Разведка ограничена 3 000 контактами и 15% стартового денежного бюджета;
  при малом бюджете допускается стоимость одного минимального пилота из
  10 контактов, если сохраняются ресурсы fallback. Общие лимиты среды строже.
- Платный канал проверяется отдельно после подтверждённого дешёвого; публичный
  conversion multiplier только предлагает гипотезу. На финал нельзя дважды
  выбрать одну аудиторию. Без подтверждений берётся допустимая ячейка с
  минимальным baseline ARPU + стоимостью контактов, а не большая noisy победа.
- `runtime/` подключает один внешний запрос ранжирования. LLM возвращает
  только перестановку ID, не бюджеты/фильтры/порог/финальный план. Ключи из
  процесса или `.env`, фиксированные HTTPS endpoints без redirects, timeout
  15 с, ограничение ответа 256 KiB и JSON-валидация. Ошибки дают наблюдаемый
  deterministic fallback, без тела ответа или секретов в логах.
- `agent.py` и backend используют общую фабрику. `FP_LLM_PROVIDER=off` по
  умолчанию; opt-in `nvidia|openai`. Переключение явно задаёт оператор,
  автоматического второго платного запроса нет. Экспорт submission проверяется
  с принудительным `off`; сетевой режим не обещает побайтной воспроизводимости.

## Проверка и ограничения

Сценарные unit tests не используют скрытую модель mock: одиночный всплеск,
неустойчивые повторения, устойчивое подтверждение, стоимость канала, реальные
остатки после повреждённого ответа, минимальный fallback, ограничения LLM.
Backend больше не предполагает ровно три пилота; отрицательный net остаётся
успешно завершённым вычислением.

Первая версия gate (два повторения, штраф 1.5) была хуже baseline по нижнему
хвосту и отклонена; её диагностический отчёт сохранён. Финальная политика
зафиксирована до отложенных seed 100–139. На них средний net и нижний хвост
улучшились, однако убыточны 17/40 запусков. На seed 0–9 ухудшились медиана и
доля прибыльных запусков. Ни один mock-отчёт не прогнозирует hidden score.

NVIDIA default model: `nvidia/llama-3.1-nemotron-51b-instruct`, присутствует в
каталоге; inference с текущим ключом 401. OpenAI `gpt-4.1-mini` после обновления
ключа дал реальные валидные ответы. Положительный HTTP /models сам по себе
не считается успешным inference. Результаты — в `docs/benchmarks/`.

Источники адаптеров: [NVIDIA API Quickstart](https://docs.api.nvidia.com/nim/docs/api-quickstart),
[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).

# ADR 0003 — OpenAI как единственный внешний советник

Дата: 2026-09-23. Статус: implemented.
Заменяет только выбор провайдеров ADR 0002.

После отсутствия Казахстана в форме верификации NVIDIA пользователь явно
отменил её использование. Удалены NVIDIA endpoint, конфигурационные ключи,
модель и CLI option. Runtime поддерживает `off` (default) и `openai`.
OpenAI payload/model, fallback, ограничения сети, core и OpenAPI не менялись.

Локальный `.env` не редактировался: остаточные NVIDIA-переменные игнорируются.
Если в окружении терминала сохранился `FP_LLM_PROVIDER=nvidia`, нужно явно
заменить его на `openai` или `off`; старое значение даёт понятный ValueError.
Default остаётся offline для повторяемости судейских запусков и CSV.

Исторические handoff и benchmark JSON сохраняются; они отражают состояние
предыдущей итерации. Новый handoff 05 и PROJECT_STATE описывают текущую.
Новые платные запросы для удаления адаптера не нужны: OpenAI Responses
не изменён, повторены unit/API/HTTP/judge проверки без внешних вызовов.

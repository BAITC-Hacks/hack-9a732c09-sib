Текущий формат ответа и диагностика ошибок проверены тестовыми ответами;
новый live benchmark ещё не выполнен. Не приписывать старые числа новому prompt.

Официальный `local_eval.evaluate_agent`, неизменённые mock effects/data/scorer.
Один seed соответствует шуму/выборке пилотов; реальные скрытые эффекты
судейства могут отличаться. Net включает пилоты и финал после дедупликации.

`adaptive-initial-diagnostic.json` — отклонённый первый вариант: две
положительные реплики и penalty 1.5; худший net −90 616. После диагностики
выбран gate из трёх положительных реплик, penalty 2 и проверка доступности
трёх пилотов для платного канала. `adaptive-diagnostic.json` фиксирует этот
вариант. Политика была заморожена до просмотра seed 100–139 в
`adaptive-holdout.json`; изменения обработки конфигурации её не меняют.

Улучшение среднего не означает улучшение всех критериев: offline на seed
0–9 ухудшил медиану и долю положительных прогонов. На holdout остаются
17 убыточных запусков из 40. Часто используется крошечный fallback, а
результат обеспечивают только пилоты. Эвристический порог не даёт гарантии
ошибки первого рода, независимости повторов или отсутствия потерь.

`openai-smoke.json`: реальный Responses API `gpt-4.1-mini`, seed42,
external_advisor_used=true, net≈587 846. `openai-diagnostic.json`:
10 реальных принятых ответов, 8/10 прибыльных прогонов. Это небольшая
диагностическая серия, не отложенная оценка качества LLM. Она не доказывает
превосходство модели на hidden effects. Сетевой порядок может меняться даже
при одинаковом seed, поэтому эти отчёты нельзя обещать воспроизвести побайтно.

`nvidia-smoke.json` — не успешная проверка NVIDIA: inference вернул HTTP 401,
external_advisor_used=false, отработал deterministic fallback. Каталог моделей
доступен, но это не доказательство авторизации inference. Проверенный доступный
в каталоге `nvidia/llama-3.1-nemotron-51b-instruct` также вернул 401.
Обновлённый пользователем OpenAI-ключ после этого дал HTTP 200 и реальные ответы.

Baseline/thresholds не содержат blacklist тарифов, seed-ветвлений или скрытой
модели. Для дальнейшего сравнения нужны новые seed и одинаковые условия;
не выбирать удачный одиночный прогон как демонстрацию устойчивости.
